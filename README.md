# Collective Context-Aware Communication in Agent Networks: Ontology-Grounded Stigmergy for Collective Intelligence

Simulation code for the case studies in the paper of the same name.

## Installation

```
pip install -r requirements.txt
```

Python 3.10+. Only `figures/` needs a third-party package (`matplotlib`); the simulation itself is pure standard library.

## Repository layout

```
field_sim/                 the simulation: agents, environment, ontology, collective context,
                            selective transmission, and evaluation against ground truth
field_sim/experiments/     one exp_*.py per case study / analysis in the paper (Section V)
figures/                   make_*.py scripts that draw Figs. 3-5 from saved results (no
                            simulation run here); fig_*.pdf are the ones used in the paper
```

| Paper result | Script |
|---|---|
| Fig. 3 - collective knowledge gain vs. sensing radius (V.A) | `exp_ccg_vs_fragmentation.py` → `make_ccg_vs_fragmentation.py` |
| Fig. 4 - uplink cost vs. number of agents (V.B) | `exp_agent_count.py` → `make_agent_count_per_agent.py` |
| Fig. 5 - uplink/downlink/total cost vs. sync. period (V.C) | `exp_sync_messages.py` → `make_sync_messages.py` |
| Inference provenance, multi-agent support (V.A) | `exp_inference_provenance.py` |
| Heterogeneous representation / ontology-mapping ablation (V.A) | `exp_alias_mapping.py` |
| Decay-rate sweep (V.C) | `exp_decay_sweep.py` |
| Budgeted priority / conflict-detection latency (V.B) | `exp_budget_conflict_latency.py` |

## Running

```
python -m field_sim.experiments.exp_ccg_vs_fragmentation   # etc. - writes results_main/ or results_additional/<name>/
python figures/make_ccg_vs_fragmentation.py                # etc. - reads those results, writes figures/fig_*.{png,pdf}
```

`results_main/`, `results_additional/`, and `figures/*.png` are gitignored - all regenerated by the commands above (fixed seeds 0-7; each script's own `validate()` checks it reproduces the saved numbers).
