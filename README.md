# Collective Context-Aware Communication in Agent Networks: Ontology-Grounded Stigmergy for Collective Intelligence

Simulation code for the case studies in the paper of the same name (Eun Choi, Hyowoon Seo).

Mobile agents observe a shared environment and selectively deposit ontology-grounded semantic traces into a shared collective context, which evolves through reception, temporal decay, and reasoning over ontology rules - and in turn guides later transmissions.

## Installation

```
pip install -r requirements.txt   # matplotlib; Python 3.10+
```

## Layout

- `field_sim/` - the simulation (agents, environment, ontology, collective context, selective transmission, evaluation)
- `field_sim/experiments/` - one `exp_*.py` per case study in Section V
- `figures/` - `make_*.py` scripts drawing Figs. 3-5 from saved results; `fig_*.pdf` are the ones used in the paper

| Paper result | Script |
|---|---|
| Fig. 3, gain vs. sensing radius (V.A) | `exp_ccg_vs_fragmentation.py` → `make_ccg_vs_fragmentation.py` |
| Fig. 4, uplink cost vs. agent count (V.B) | `exp_agent_count.py` → `make_agent_count_per_agent.py` |
| Fig. 5, cost vs. sync. period (V.C) | `exp_sync_messages.py` → `make_sync_messages.py` |
| Provenance / heterogeneous-mapping / decay / budget analyses (V.A-C) | `exp_inference_provenance.py`, `exp_alias_mapping.py`, `exp_decay_sweep.py`, `exp_budget_conflict_latency.py` |

## Running

```
python -m field_sim.experiments.exp_ccg_vs_fragmentation   # etc. -> results_main/ or results_additional/<name>/
python figures/make_ccg_vs_fragmentation.py                # etc. -> figures/fig_*.{png,pdf}
```

Results and `figures/*.png` are gitignored - both regenerated by the commands above (seeds 0-7).
